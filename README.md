# KiKAiTO customer requirements and communication

## Purpose of this space

- This is the customer space for confirming requirements, giving feedback and reviewing completed features.
- After a requirement is confirmed, the team tracks its build tasks in a separate private development workspace. The original requirement and your replies stay here.
- We report progress and results on the relevant feature issue: what you can do, where to try it, what you will see and anything still pending.
- Agreeing to a plan is separate from accepting the demonstrated result. We record your actual confirmation and the scope it covers.

View [all features and progress](https://github.com/BTTSpace/KiKAiTO-client-communication/issues/2) or [questions for you](https://github.com/BTTSpace/KiKAiTO-client-communication/issues/3). The English website is being revamped; the existing Chinese pages remain available.

- [Label meanings](docs/labels.md)
- [How to read and reply](https://github.com/BTTSpace/KiKAiTO-client-communication/issues/1)
- [Homepage feedback FR-2026-10-12-01](https://github.com/BTTSpace/KiKAiTO-client-communication/issues/18)
- [Received documents](docs/customer-feedback/README.md)
- [Feature scope](docs/scope-v2.md)

Each issue shows English first, with Chinese below. Reply in either language, in an issue comment or via LINE with the issue number.

- `needs-customer-response`: a reply is required.
- `needs-customer-decision`: each question has a recommendation and a reason. Within a plan you have confirmed, if no change is needed, we proceed with that recommendation. For a change, select another option or “Other” and describe your proposal; comment or reply via LINE.

After each feature is implemented, we provide screenshots; for motion or interactive features, also provide a demonstration video or an interactive demo. When the demo link is provided, review the shown version and tell us what should change or confirm that it meets the acceptance list. This is the feature-planning stage; those demonstrations follow implementation.

This repository is public. Send private materials through LINE.

# KiKAiTO 客戶需求溝通與驗收

## 此倉庫的用途

- 這裡是客戶需求確認、回饋及功能驗收的溝通空間。
