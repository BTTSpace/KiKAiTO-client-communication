# Product quotation demonstration — customer features #7 and #10

- Demonstrated version: English preview 2026-11-02, the same preview candidate used for the previously published review captures. This is a later native-mail capture of that preview, not a claim about the current live website.
- Captured 2026-11-03 in Asia/Taipei; website content comes from the 2026-09-24 archive. The English translation is an example and has not been customer-approved.
- Environment: Chrome desktop and Claws Mail 4.3.1. The reserved `.test` addresses shown, including `demo.example.test`, are local demonstration addresses, not the live website; sender and recipient are examples.

- [Setting page](setting.png) — features #7 and #10: before saving, the administrator has changed the quotation recipient to `demo+review@example.test`.
- [English quotation entry](quotation-entry.png) — features #7 and #10: at the end of the Expansion anchors product page, the visitor can select “Request a quotation by email”.
- [Prepared email](compose.png) — features #7 and #10: after the administrator saves that address and the visitor selects the entry, the email opens with `demo+review@example.test` as recipient, “Quotation request: Expansion anchors” as subject, and product `Expansion anchors`, model `膨脹螺絲`, and the current demonstration page address in the body. Quantity, Destination and Message are blank for the visitor to fill.
- [Recording](admin-to-compose.webm) — features #7 and #10: shows the setting change and save, English product entry, and the prepared email in sequence. No message was sent.

This demonstrates one desktop browser and one configured email client. Other email clients and physical phones were not tested. This material is for review; owner verification and customer acceptance remain pending.
